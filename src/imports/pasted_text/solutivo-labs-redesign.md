REDESIGN / BUILD A COMPLETE WEBSITE FOR:

SOLUTIVO LABS INDONESIA

The website should be inspired by the visual language, editorial composition, cinematic presentation, typography, spacing, motion, and gallery-driven storytelling of modern aerospace / defense technology company websites such as Anduril Industries.

IMPORTANT:
DO NOT COPY ANDRUIL'S WEBSITE, LOGO, TEXT, BRANDING, COLORS, ASSETS, OR EXACT LAYOUT.

Instead, reinterpret the same design principles into an original Solutivo Labs visual identity.

The final result must feel like a premium technology company, AI engineering studio, and digital product laboratory.

==================================================
CORE CREATIVE DIRECTION
==================================================

Think:

CINEMATIC
INDUSTRIAL
EDITORIAL
MINIMAL
TECHNICAL
PREMIUM
FUTURISTIC
CONFIDENT
QUIETLY AGGRESSIVE

The website should NOT look like:

- a generic SaaS landing page
- a startup template
- a WordPress agency website
- a typical Indonesian software house
- a page full of rounded cards
- a page full of gradients
- excessive glassmorphism
- excessive shadows
- excessive icons
- generic stock illustrations

Avoid the typical:
"Empowering businesses with innovative digital solutions."

Instead, communicate through typography, imagery, projects, products, and motion.

==================================================
SCROLL BEHAVIOR
==================================================

The website must feel highly animated but sophisticated.

Use animation principles inspired by premium editorial websites.

Implement:

- scroll-triggered text reveals
- image scale from 1.08 → 1
- clip-path image reveals
- horizontal image movement
- subtle parallax
- sticky sections
- staggered typography
- opacity transitions
- slight blur → sharp transitions
- section entrance animations
- horizontal scrolling galleries

Animations must be smooth and slow.

Avoid:
- bouncing
- excessive spring animations
- flashy transitions
- unnecessary 3D effects
- animation on every single element

Motion should communicate hierarchy.
